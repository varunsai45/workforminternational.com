# Workform International Website

A responsive multi-page website starter for Workform International, built with React, TypeScript and Vite.

## Included

- Responsive multi-page website and shared navigation
- Homepage, About, Services, Industries, Manufacturing, Projects, Contact and Quote pages
- Local image assets and supplied Workform logo
- SEO title/description handling, robots.txt and sitemap.xml
- WhatsApp, phone, email and Google Maps links
- Project enquiry form
- Vercel and Netlify SPA route configuration

## Requirements

- Node.js 20 LTS or newer
- npm
- A code editor such as Visual Studio Code

## Run locally

1. Extract the ZIP.
2. Open the extracted `Workform-International-Website` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite, normally `http://localhost:5173`.

## Build for production

```bash
npm run build
npm run preview
```

The production website files are created in `dist/`.

## Enquiry form

The enquiry form formats the customer's submitted details into a WhatsApp message addressed to Workform at +91 99007 16198. The customer must review and press Send in WhatsApp; the website does not send the message automatically.

## Important content review before launch

- The factory image is an illustrative generated visual, not a verified photograph of Workform's actual facility. Replace it with approved factory photography before publishing.
- Other office images are generated architectural concept imagery.
- A dedicated generated factory-production photograph is used for industrial and manufacturing content.
- Project cards are explicitly labelled as illustrative concepts, not completed Workform projects.
- Confirm the supplied 40,000 sq. ft. facility statement and German sourcing statement with the company before publication.
- Add the final domain to the canonical URL and sitemap if it differs from `www.workforminternational.com`.
- Add real social profile URLs before enabling social links.
